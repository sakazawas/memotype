Privacy Policy / プライバシーポリシー

Last updated: November 2026
最終更新: 2026年11月

English
1. Overview
Memotype is a repetition learning application developed by sakazawa.

This Privacy Policy explains how data is handled by the current version of Memotype.

2. Data Stored by Memotype
Memotype stores study-related data locally on the user's device.

The locally stored data may include:

Questions and answers created or edited by the user
Number of correct answers
Total number of questions
Elapsed study time
Study records used for local ranking and history features
This information is used only to provide Memotype's study and record-keeping functionality.

3. External Data Transmission
The current version of Memotype does not transmit the user's study data to the developer or to external servers.

Memotype does not currently use:

User accounts or login services
Cloud synchronization
Advertising services
Analytics services
Firebase services
Developer-operated servers for collecting study data

4. Audio
The correct-answer sound used by Memotype is included as a local application asset.

The application does not retrieve this sound from an external audio service during normal use.

5. Personal Information
Memotype does not require the user to provide personal information such as a name, email address, address, or telephone number in order to use the current version of the application.

Users may enter their own text as study questions and answers. This content is stored locally on the user's device.

Users should avoid entering sensitive personal information into study items if such information is not necessary for their learning purposes.

6. Data Storage and Deletion
Study data is stored locally using the application's local storage mechanism.

Memotype does not maintain a remote copy of this data.

Users are responsible for managing data stored on their own device.

7. Third-Party Components
Memotype is built with Flutter and uses open-source software components.

Third-party components may be subject to their respective licenses and policies.

8. Future Changes
Future versions of Memotype may introduce additional features.

If a future version introduces functionality that changes how user data is collected, stored, or transmitted, this Privacy Policy will be updated accordingly.

9. Developer
Developer: sakazawa

日本語
1. 概要
Memotypeは、sakazawaが開発する反復学習アプリケーションです。

本プライバシーポリシーは、現在のMemotypeにおけるデータの取り扱いについて説明します。

2. Memotypeが保存するデータ
Memotypeは、学習に必要なデータを利用者の端末内に保存します。

保存されるデータには、次の情報が含まれる場合があります。

利用者が作成または編集した問題と回答
正答数
問題総数
学習時間
ローカルランキングおよび学習記録機能に使用する学習記録
これらの情報は、Memotypeの学習機能および学習記録機能を提供するために使用されます。

3. 外部へのデータ送信
現在のMemotypeは、利用者の学習データを開発者または外部サーバーへ送信しません。

現在のMemotypeでは、以下の機能を使用していません。

ユーザーアカウントまたはログインサービス
クラウド同期
広告サービス
アクセス解析サービス
Firebaseサービス
学習データを収集するための開発者運営サーバー

4. 音声
Memotypeで使用する正解音は、アプリケーション内のローカルアセットとして収録されています。

通常の利用時に、この正解音を外部の音声サービスから取得することはありません。

5. 個人情報
現在のMemotypeを利用するために、氏名、メールアドレス、住所、電話番号などの個人情報を入力する必要はありません。

利用者は、学習用の問題および回答として任意の文章を入力できます。これらの内容は利用者の端末内に保存されます。

学習上必要でない場合は、機微な個人情報を学習項目として入力しないことを推奨します。

6. データの保存と削除
学習データは、アプリケーションのローカルストレージ機能を使用して利用者の端末内に保存されます。

Memotypeはこれらのデータのリモートコピーを保持しません。

端末内に保存されたデータの管理は、利用者自身が行います。

7. サードパーティコンポーネント
MemotypeはFlutterを使用して開発され、オープンソースソフトウェアのコンポーネントを利用しています。

サードパーティコンポーネントには、それぞれのライセンスおよびポリシーが適用される場合があります。

8. 将来の変更
今後、Memotypeに新しい機能が追加される場合があります。

利用者データの収集、保存または送信方法に影響する機能を追加した場合、本プライバシーポリシーを必要に応じて更新します。
